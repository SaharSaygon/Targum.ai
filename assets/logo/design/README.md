# Targum.ai logo — design source

Live, editable canvas (Claude Design preview): https://claude.ai/code/artifact/377c265c-41dd-43bf-8bff-3b191967c7b1

- `*.dc.html` — the artboards (Directions page: Main, Ligature, Interlinear, Wordmark, Bookmark;
  Develop page: Refinements, Lockups; Final page: Final). Plain HTML/SVG, editable by hand.
- `canvas.json` — artboard layout and pages.
- `targum-logo-directions.html` — the self-contained canvas file; opens in any browser for
  viewing and PNG/PDF export (the same file that is published at the link above).

Final mark: heavy Tת ligature, cold blue bar (#2a6db3) on ink (#141b24), paper #f2f5f8.
Exported assets live one level up in `assets/logo/`.
